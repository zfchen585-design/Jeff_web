# Zhaofu (Jeff) Chen Personal Website

Static GitHub Pages site inspired by a clean academic sidebar layout.

Live site: <https://zfchen585-design.github.io/Jeff_web/>

## Files

- `index.html` - site content and sections.
- `styles.css` - responsive academic-style layout.
- `script.js` - section navigation and hash routing.
- `assets/Zhaofu_Jeff_Chen_CV_2026.pdf` - October 2026 CV supplied for this update.
- `assets/APS_ENZ_Poster_2026.pdf` - APS conducting-polymer ENZ poster.
- `assets/IRT_Memristor_Poster_2026.pdf` - CALIT2 UROP IRT memristor poster.
- `assets/CCAM_Poster_DONE.pdf` - earlier CCAM poster.
- `assets/profile-photo.jpg` - sidebar profile image.
- `assets/*-preview.png` - poster preview images.

The medium-entropy-oxide manuscript had a ChemRxiv version in 2025 that was later withdrawn. Its entry on the site describes the current revision status. Do not present the old version or its screenshot as an active preprint.

Publication entries distinguish peer-reviewed work, a submitted manuscript, a manuscript under revision, and work still in preparation. The Skills & Instruments section names equipment only where the supplied CV, poster, or earlier CV records support it.
